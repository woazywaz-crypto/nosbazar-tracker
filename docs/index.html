Configurer le bouton (une seule fois par appareil)

Pour lancer un relevé depuis cette page, GitHub demande une clé d'accès. Elle reste uniquement dans ce navigateur et n'est envoyée qu'à GitHub.

  1. Ouvre github.com/settings/personal-access-tokens/new (connecté avec ton compte perso).
  2. Nom : bouton nosbazar. Expiration : celle que tu veux (1 an par exemple).
  3. Repository access : Only select repositories → nosbazar-tracker.
  4. Permissions → Repository permissions → Actions : Read and write. Rien d'autre.
  5. Clique sur Generate token, copie la clé et colle-la ci-dessous.
